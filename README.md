# VISION 2000 — Site officiel

V1 du site vitrine de Vision 2000.

## Contenu
- Accueil premium responsive
- Collections
- Services
- Présentation de la marque
- CTA WhatsApp
- Formulaire de contact connecté à WhatsApp
- Design responsive mobile / tablette / desktop
- Aucun framework requis

## Déploiement
Compatible avec GitHub Pages : **Settings → Pages → Deploy from branch → main → /(root)**.
